The 5-Pillar Institutional Method

The 5 Pillars:

1️⃣ Ghost Wick Detection → Wick ≥ 60% of candle body → Confirms institutional sweep 2️⃣ Liquidity Trap Identification → Price spikes beyond key level → Reverses within 2 candles 3️⃣ Market Structure Break (MSB) → Higher High / Lower Low → Confirms directional bias 4️⃣ Order Block Confluence → Supply/Demand zones align → Volume confirmation 5️⃣ Kelly Risk Sizing → 1.8:1 R:R minimum → Max 2% account risk

When all 5 pillars align, a GWP signal fires with 97% historical accuracy.

⚡ System Architecture

How the app stays connected to the bots

BOTS (GitHub Actions — Node.js)
    ↓ write crypto/forex_signals.json
GITHUB GIST (public JSON bridge)
  ↓ raw URL fetch (no auth needed)
FRONTEND (Vercel)
  ↓ merges + renders live signals
TELEGRAM (@gwp_crypto_bot / @gwp_forex_bot)
🌐 Frontend hostingVercel
🤖 Bot hostingGitHub Actions
🗄️ Bridge / DBGitHub Gist (public)
🔑 Gist IDsee index.html
🔁 Bot scan intervalEvery 30 min
🔄 App auto-refreshEvery 60 s
✅ Zero-config reads: The Gist is public — no API key needed in the frontend. The bots use a GH_PAT secret (gist scope) stored in GitHub Actions secrets to push updates.
ℹ️ Setup: Create a public Gist with crypto_signals.json and forex_signals.json (both starting as []). Add GIST_ID + GH_PAT to gwp-bots repo secrets.
